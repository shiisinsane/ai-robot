## 1. 阶段目标

在M5冻结的地图、定位、导航、感知与安全能力之上，建立不依赖AI的ROS 2任务管理器，以结构化
任务驱动导航和到点感知，统一处理校验、反馈、取消、超时、失败传播和结果汇总，并通过正常、
越界、不可达、故障、安全触发、重复执行和资源场景完成仿真机器人综合验收。

M6不解析自然语言，不接入大模型或AI Agent，不实现目标识别或语义导航，不操作实体机器人，
不执行G1硬件准入。

## 3. 冻结场景矩阵

| 类别 | 场景 | 必须证明的结果 |
|---|---|---|
| 正常 | 合法目标导航并采集到点感知 | 状态迁移完整，导航成功，感知数据新鲜，结果可追溯 |
| 输入 | 地图外、非法Frame、非有限数值 | 下游运动前拒绝，错误码稳定 |
| 导航 | 障碍内或不可达目标 | 任务失败，下游Action结束，机器人停车 |
| 控制 | 用户取消、端到端超时 | 取消传播，不遗留活动目标或非零命令 |
| 并发 | 执行中提交第二任务 | 按W2冻结策略明确拒绝或受控替换，不隐式并行 |
| 感知 | 到点后数据缺失或过期 | 不把旧数据报告为成功，返回可区分失败 |
| 安全 | 雷达、IMU、里程计、定位断流或停车锁存 | 任务失败关闭，安全状态优先，错误原因可追溯 |
| 重复 | 同一综合任务多轮执行 | 成功率、终点精度、结果一致性和资源占用达标 |

## 4. 关键验收条件

- [x] M5冻结输入、M6范围、非目标、候选资源和回退边界明确；
- [x] 正常、输入、导航、控制、并发、感知、安全和重复场景已冻结；
- [x] 非AI任务Action、反馈、结果、错误码和版本完成契约测试；
- [x] 任务管理器只调用白名单公共能力，不发布速度命令或绕过安全链；
- [x] 合法综合任务完成导航、到点感知和结构化结果返回；
- [x] 非法、越界和并发任务在产生运动前被拒绝；
- [x] 不可达、取消、超时、感知过期和安全故障正确传播并受控收尾；
- [x] 重复综合任务、实时因子、CPU、RSS和接口频率达到W2冻结门限；
- [ ] M1～M5接口、导航、感知和安全能力无退化；
- [ ] 自动回归、最小rosbag、回放、日志、快照和SHA-256完整；
- [ ] 全部测试不连接实体设备或AI Agent。

## 5. 完成判定与当前入口

只有M6-W1～W9全部完成、验收条件关闭、阻塞项清零或形成经用户确认的延期处置，才可进入
M6-W10正式验收。M6正式验收通过后才归档并准备G1输入；G1仍需单独启动和正式准入结论。

M6-W1～W2已完成。`robot_interfaces`生成`ExecuteRobotTask`与`SensorSnapshot`，公共接口形成
兼容扩展`m1.v2`；8个状态、13个错误码、单活动任务、并发拒绝、取消、时间和安全优先级均已
通过机器契约及接口生成验证。

M6-W3已完成：任务服务端可被发现，非法目标返回稳定错误码，合法目标在导航尚未接入时明确
失败，并发目标被拒绝，取消进入`CANCELED`，诊断可见且未发布速度命令。

M6-W4已完成：结构化任务调用M5公共导航Action，反馈依次覆盖接受、校验、导航和感知；0.4 m
目标实际到点误差`0.096 m`。因W5快照尚未接入，任务按边界返回`ERROR_SENSOR_UNAVAILABLE`。
用户已于2026年8月12日使用Gazebo GUI复验并确认通过；三终端启动、脚本下发、人工观察点
和通过标准已固化在`M6_W4导航任务编排验证_2026-08-12.md`。

M6-W5已完成：导航成功后按ROS时间等待雷达、RGB图像和公共全局位姿在`0.5 s`门限内同时
新鲜，返回包含360点雷达元数据、`640×480 rgb8`图像元数据、全局位姿和最终位姿的结构化
结果。端到端任务返回`SUCCEEDED`，0.4 m目标误差`0.099 m`；数据缺失、过期、取消、超时和
安全停车均有受控终态。为保证静止到点时公共位姿持续新鲜，AMCL运动更新阈值调整为零并已
通过全仓回归。

M6-W6已完成：活动任务期间第二目标被Action层明确拒绝；用户取消在`0.033 s`内传播到公共
导航Action并确认下游终止；10秒任务总超时在`10.059 s`返回`ERROR_TASK_TIMEOUT`且不遗留
活动导航；相同目标连续执行2/2成功并分别返回完整快照。取消、安全停车和超时后的下游终态
确认统一使用W2冻结的2秒门限，未确认时返回内部错误而不伪装为受控关闭。

M6-W7已完成：地图外、非法Frame和非有限目标3/3在导航前拒绝；障碍内目标稳定返回
`ERROR_NAVIGATION_FAILED`；相机断流返回`ERROR_SENSOR_STALE`，不使用旧图像报告成功；雷达、
IMU和融合里程计断流分别在`0.262 s`、`0.178 s`和`0.150 s`内停止非零安全命令并返回
`ERROR_SAFETY_STOP`；AMCL断流由定位看门狗返回`ERROR_NAVIGATION_FAILED`。全部任务终态均无
活动下游导航目标。任务管理器在映射下游终态前复核安全状态，关闭安全故障被降级为普通导航
失败的竞态。

M6-W8已完成：`(0.8,0.0)`与原点间五轮“导航＋到点感知”综合任务5/5成功，每轮均返回完整
四阶段反馈、360点雷达、`640×480 rgb8`图像和全局位姿；平均耗时`22.237 s`、最大
`61.901 s`，最大位置误差`0.101 m`、最大角度误差`0.069 rad`。30秒性能窗口实时因子
`0.941`、CPU峰值`299.5%`、RSS峰值`668.0 MiB`；雷达、里程计、`map→odom`和
`odom→base_link`频率分别为`15.150`、`49.995`、`15.149`和`49.995 Hz`，均达标。

当前入口为M6-W9自动回归与证据。未经用户确认不进入W9；未经M6正式验收不得进入G1，G1
通过前不得进入实体机器人开发。
