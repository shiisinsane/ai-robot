# W6 A1控制变量验证实验报告

> 日期：2026-08-26
> 数据版本：`roa-validation-a1-v0.1`
> 状态：30项有效任务已按预注册方案完成并封板
> 适用边界：仅限当前ROS 2/Gazebo仿真配置，不外推实体机器人或真实运营

## 1. 结论

在固定`return_home`路线、起终点、无定位扰动、baseline参数和90秒超时，仅改变障碍档位及
冻结位置的条件下，A1得到控制实验支持：

- `low`组0/15失败，失败率0%，Wilson 95%区间为0%～20.39%；
- `medium`组15/15失败，失败率100%，Wilson 95%区间为79.61%～100%；
- `medium - low`绝对失败风险差为+100个百分点；
- 15项`medium`失败均为错误码201，`low`组为0/15；
- 双侧Fisher精确检验`p=1.289345×10⁻⁸`；
- 因`low`组观测失败率为0，风险比不可定义，不用无依据的连续性修正制造数值。

该结果支持“冻结的medium障碍配置提高当前仿真任务的导航失败风险”，但不证明所有中等障碍、
其他路线、其他参数或实体机器人都会得到相同结果。

## 2. 实验与数据质量

实验严格使用预注册的15个平衡配对块，共30项有效任务，每组15项；未提前停止，也未按结果追加
样本。冻结计划SHA-256为
`e83ec04ebeff4818bed12f66e94cd6e6450e7ecb50bdad731f5028831581452d`，配置SHA-256为
`51ade767739f2771c60d5e6005b8683dd370c47771ce7ae339fec5e747c41eaf`。

运行中另有7次环境无效尝试，均保留在独立批次目录且未计入主要分析：

- `a1-slot-001`：受限沙箱环境无法正常建立ROS/Gazebo通信；
- `a1-slot-003`、`a1-slot-019`：正式任务前起点准备未成功；
- `a1-slot-003-retry-001`、`a1-slot-005`、`a1-slot-029`、`a1-slot-030`：Nav2未在门限内全部Active。

所有无效尝试均未替换组别，只重试原计划槽位；没有槽位达到连续三次无效暂停阈值。30个有效
批次均通过样本门禁和本轮进程清理检查。有效任务的必需遥测覆盖率为100%，无传感器过期任务，
无安全停车任务。

## 3. 效率与机制观察

| 指标 | low | medium |
|---|---:|---:|
| 有效任务数 | 15 | 15 |
| 成功 / 失败 | 15 / 0 | 0 / 15 |
| 周期均值（秒） | 38.392 | 9.709 |
| P50 / P90 / P95（秒） | 36.106 / 47.617 / 51.955 | 9.449 / 13.104 / 13.491 |
| 前3秒平均绝对线速度（m/s） | 0.000008 | 0.000180 |
| 进入到点感知 | 15/15 | 0/15 |
| 观测最小障碍距离（m） | 0.533 | 0.322 |

`medium`周期更短不是效率改善，而是任务更早以导航失败终止。所有`low`任务进入到点感知，所有
`medium`任务均未进入，说明分离发生在导航阶段。

预注册的连续早期速度指标并未支持“medium失败由更低早期速度表征”：`medium`组均值反而更高。
因此，探索数据中的`0.005 m/s`阈值继续只作为探索性线索，不能作为已验证机制或决策规则。

最小障碍距离只报告观测值。由于实验前没有冻结安全距离阈值，“无安全停车”和上述距离不能被
写成“安全验收通过”。
