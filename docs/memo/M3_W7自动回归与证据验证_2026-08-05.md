## 1. 统一回归入口

新增统一入口：

```bash
./scripts/run_m3_regression.sh
```

入口首先完成全仓构建和测试，随后为雷达、相机、IMU和编码器依次分配独立
`ROS_DOMAIN_ID`、`IGN_PARTITION`、ROS日志目录和Gazebo目录。每类传感器单独启动、检查
公共Topic的消息类型与QoS、执行数据语义检查、录制最小rosbag、检查完整性并在另一隔离ROS
域中只读回放。编码器场景额外回归M2运动、停车、TF、限速、超时和非有限命令安全行为。

任一Launch、检查、录制、回放或清理失败时入口返回非零退出码。最终自动保存权威配置快照、
运行日志、Topic运行图、检查输出、rosbag、摘要、证据清单、文件大小和SHA-256。
