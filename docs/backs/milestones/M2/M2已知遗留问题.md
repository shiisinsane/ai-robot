# M2已知遗留问题

以下事项不阻止M2验收，但必须在对应后续阶段继续处理。

| 遗留事项 | 风险 | 后续入口和关闭条件 |
|---|---|---|
| 根Link带惯量产生KDL提示 | 某些KDL使用方不能表达根Link惯量 | 后续模型结构调整或KDL能力接入时评估虚拟根Link，并重新执行模型与TF回归 |
| 仿真周期`0.001 s`与控制周期`0.01 s`存在提示 | 高负载时实时因子可能下降 | M4系统集成和性能测试记录实时因子、控制频率和资源占用 |
| 安全过滤节点当前只过滤非有限数值 | 后续多源命令仍需仲裁、急停和状态监督 | M4安全集成中实现完整`SafetySupervisorNode`和故障注入 |
| 原始W8证据只存于本地`artifacts/` | 本地删除后只能依靠摘要和哈希追溯 | 首次需要长期保存大型证据前确定外部存储和保留策略 |
| M2验收变更尚未形成Git基线提交 | 当前验收内容尚无最终提交ID | 用户另行授权提交后，在后续记录中补充基线；标签仍需单独授权 |

M3、G1、G2和实体安全边界继续有效，不得用上述遗留事项绕过阶段门。
