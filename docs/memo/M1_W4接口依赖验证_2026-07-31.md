# M1-W4接口依赖验证记录

**验证日期：** 2026年7月31日

**环境：** Ubuntu 22.04 + ROS 2 Humble

**范围：** W4遗留的3项`nav2_msgs`接口类型验证

## 1. 验证对象

| 公共接口 | ROS 2类型 | 结果 |
|---|---|---|
| `/robot/navigation/navigate_to_pose` | `nav2_msgs/action/NavigateToPose` | 通过 |
| `/robot/navigation/follow_waypoints` | `nav2_msgs/action/FollowWaypoints` | 通过 |
| `/robot/map/save_map` | `nav2_msgs/srv/SaveMap` | 通过 |

## 2. 软件包来源

- Debian包：`ros-humble-nav2-msgs`
- 版本：`1.1.20-1jammy.20260605.153126`
- 架构：`amd64`
- 软件源：当前系统配置的ROS 2 Humble Ubuntu软件源
- SHA-256：
  `ac3521b82f07b65a896194f914a6ba3067d53570be85bcc8f99dfcfdbe5f47f9`

由于当前自动化环境无法交互输入`sudo`密码，本次将官方Debian包下载到临时目录并隔离
解包，通过临时`AMENT_PREFIX_PATH`执行类型解析；没有修改系统安装状态。

## 3. 验证命令

```bash
apt-get download ros-humble-nav2-msgs
dpkg-deb -x ros-humble-nav2-msgs_*.deb extracted
source /opt/ros/humble/setup.bash
export AMENT_PREFIX_PATH="$PWD/extracted/opt/ros/humble:$AMENT_PREFIX_PATH"
ros2 interface show nav2_msgs/action/NavigateToPose
ros2 interface show nav2_msgs/action/FollowWaypoints
ros2 interface show nav2_msgs/srv/SaveMap
```

三个`ros2 interface show`命令均成功返回完整接口定义。由此确认
`config/common/interface_contract.yaml`使用的包名、接口类别和类型名称与ROS 2 Humble
实际定义一致。

## 4. 结论与后续要求

W4的3项接口依赖验证尾项已经关闭，契约状态更新为`interface_verified`。这只确认接口
定义存在且名称正确，不代表Nav2运行能力或资源准入已经完成。

W6建立可运行契约测试前仍须：

1. 将`ros-humble-nav2-msgs`安装到正式开发和CI环境；
2. 在相应ROS 2软件包中声明`nav2_msgs`依赖；
3. 将3项类型解析纳入自动契约测试。
