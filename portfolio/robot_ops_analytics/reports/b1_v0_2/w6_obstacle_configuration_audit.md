# W6中障碍配置静态审计

> 日期：2026-08-27
> 范围：仅静态读取现有配置、世界模型和Nav2参数；未启动ROS 2或Gazebo
> 结论：当前A1中障碍配置不适合作为一般化的长路线避障实验

## 1. 配置事实

- `return_home`路线为`(0.8, 0.0) → (0.0, 0.0)`，直线长度仅`0.8 m`；
- 临时障碍为`0.55 m × 0.55 m`方箱；
- `medium`障碍中心为`(0.4, 0.56)`，靠近路线一侧边界为`y=0.285 m`；
- Nav2 footprint半宽为`0.205 m`，沿原直线路径通过时，机器人外缘与障碍碰撞体仅约
  `0.285 - 0.205 = 0.08 m`物理余量；
- 全局和局部costmap的`inflation_radius`分别为`0.55 m`和`0.45 m`。

## 2. 判断

障碍本体没有在几何上完全封闭整个房间，南侧仍有大范围开放空间；但当前路线过短，障碍位于
起终点之间且离两端都很近。障碍膨胀区覆盖原始直线路径，并明显影响起点、终点附近的规划代价。

因此，A1的`medium`组15/15失败可以证明“当前冻结配置会导致导航失败”，但不能证明一般意义上
的中等障碍难以绕行。当前结果可能混合了以下效应：

1. 原始路径被障碍及膨胀层覆盖；
2. 起点和目标距离障碍过近；
3. 路线太短，规划器缺少形成稳定绕行路径的空间；
4. 障碍档位同时改变位置，`low`与`medium`不是单一连续难度变量。

## 3. 对现有数据的处理

- 保留已封板A1数据，不删除、不修改标签、不追加新样本；
- 将A1解释限定为“短路线近距离障碍配置效应”或“候选阻断配置效应”；
- 不将该结果表述为“所有中障碍场景都会失败”；
- 该数据仍可用于展示SQL异常定位和预注册控制实验流程，但不直接作为通用避障能力结论。

## 4. 新实验设计约束

后续另建数据版本，不复用A1样本编号。新场景应满足：

- 起终点距离明显大于当前`0.8 m`；
- 障碍位于无障碍条件下的原始规划路径上；
- 起点、终点均位于障碍膨胀影响区之外；
- 障碍两侧至少保留一条经footprint和costmap膨胀后仍可通行的绕行路线；
- 在采集前保存无障碍参考路径、障碍位置、净宽计算和规划可达性检查；
- 无障碍、低障碍和中障碍使用相同起终点，档位差异预先冻结；
- 先进行少量资格验证，再预注册正式样本量，且不与A1封板数据合并。

本审计不授权启动新实验。新路线坐标和障碍位置应在静态可达性设计完成后另行冻结。
