- Windows/PowerShell：`scripts/check_environment.ps1`
- Ubuntu：`scripts/check_environment.sh`

两个脚本只进行只读检查，不安装、不卸载、不修改系统配置。

## 当前结论

通过，因为当前沙箱不能访问 WSL，Ubuntu 22.04、ROS 2 Humble、`colcon`、RViz2 和
Gazebo 仍需在用户可用的 Ubuntu 环境中运行检查脚本并确认。

本记录是阶段性结果，不代表 M0 已通过。
