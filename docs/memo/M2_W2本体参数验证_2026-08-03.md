# M2-W2本体参数验证记录

## 验证范围

验证`config/common/robot_model.yaml`中的仿真首版几何、质量、惯量、轮距、轮半径、关节、
Frame、运动限制和控制器安全参数。验证不启动Gazebo或机器人运动。

## 自动检查

执行：

```bash
python3 scripts/check_robot_model.py
```

检查内容：

- 所有长度、质量、频率和惯量主对角项为有限正数；
- 惯量满足三角关系；
- 左右轮位置对称且与`0.34 m`轮距一致；
- 轮心高度与`0.075 m`轮半径一致；
- 轮轴沿`+y`，Link和Joint名称唯一固定；
- `odom → base_link`主链保持不变；
- `base_footprint`只作为`base_link`的地面投影辅助Frame；
- `cmd_vel_timeout`为`0.2 s`，使用非时间戳`Twist`模式；
- 闭环轮位置反馈、TF发布和仿真时间策略有效。

## 结论

机器参数校验、3项预期成功/失败单元测试、3项M1接口交叉契约测试及18项仓库级回归均
通过，W2关闭。当前参数仅是仿真首版；W3～W7发现接触、稳定性、轮滑或控制问题时，必须
通过参数重审流程调整。
