## 1. 阶段目标

在M4整机运动、感知、状态估计和安全链之上，建立二维SLAM、地图保存/重载、地图定位、
Nav2全局规划、局部控制与避障、恢复和取消能力，并通过重复到点、障碍、定位偏差、不可达、
超时和故障注入证明导航系统可重复、安全且可追溯。

M5不接入实体机器人、AI Agent、三维/视觉SLAM、目标识别或语义导航，不改变G1/G2阶段门。

## 3. 关键验收条件

- [x] M5范围、非目标、成熟资源候选和回退边界明确；
- [x] `slam_toolbox`、Navigation2和接口依赖正式安装并通过最小验证；
- [x] `map → odom → base_link`TF责任唯一、连续且无循环；
- [x] 建图路线形成连续、可保存、可重载且质量可量化的二维地图；
- [x] 地图定位可从冻结初始偏差收敛并保持稳定；
- [ ] 可达目标、连续航点、取消和不可达目标具有正确Action状态；
- [ ] 静态和临时障碍进入代价地图并触发安全绕行、重规划或受控停车；
- [ ] Nav2速度命令只能进入M4公共安全监督器，不存在控制器旁路；
- [ ] 雷达、里程计、IMU或定位异常时导航失败关闭且机器人安全停车；
- [ ] 重复导航精度、成功率、耗时、实时因子、CPU和RSS达到W2冻结门限；
- [ ] M1～M4接口、感知、状态估计和安全能力无退化；
- [ ] 自动回归、最小rosbag、回放、日志、配置快照和SHA-256完整；
- [ ] 全部测试不连接实体设备或AI Agent。

M5-W11正式验收。正式验收通过后才归档M5；未经用户明确授权不创建Git提交、推送或标签。

判定为SLAM/融合坐标修正并留待W5量化。M5-W3人工验证冻结为“服务端先行、RViz单独接入”，
不使用单条Launch命令同时启动Gazebo与RViz。
