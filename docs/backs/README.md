# 历史与里程碑归档

本目录保存被新版本替代的正式规划文件和已通过里程碑的只读快照：

- `planning/`：正式规划的历史版本。
- `milestones/M编号/`：对应 M 里程碑验收通过时的阶段规划与验收快照。

归档规则：

1. `docs/planning/` 只保留每个正式规划系列的最新有效版本。
2. 更新规划正文时创建新版本，不覆盖旧文件。
3. 新版本放入当前目录前，将被替代版本移动到 `planning/`。
4. 每个 M 里程碑正式验收通过后，在 `milestones/M编号/` 保存阶段规划摘录、正式验收
   记录、关键验证结果索引和已知遗留问题。
5. 仍对后续阶段有效的整份规划继续保留在 `docs/planning/`，不得因阶段归档而移走。
6. 里程碑规划摘录必须标明来源文件、文档版本和基线提交号，避免与当前规划混淆。
7. 默认开发和审查不读取本目录；需要追溯变更、阶段决策或验收证据时才读取。
8. 历史规划和里程碑归档不得因常规整理而删除或覆盖。

项目备忘、阶段交接摘要和每日 Report 保存在 `docs/memo/`。交接摘要只提供后续开发所需
的简要上下文和归档入口，不重复保存完整阶段材料。
