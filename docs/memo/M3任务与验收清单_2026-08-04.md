# M3“仿真传感器单元”任务与验收清单

> 启动日期：2026年8月4日  
> 依据：`../planning/AI机器人开发项目计划_v1.11.md`、
> `../planning/ROS2机器人开发规划_v1.7.md`  
> 输入基线：M2正式归档`../backs/milestones/M2/`、Git标签`m2`、接口版本`m1.v1`  
> 定位：M3执行与验收跟踪清单，不替代正式规划。

## 1. 阶段目标

在M2仿真本体与差速底盘基线上，分别接入激光雷达、相机、IMU和仿真编码器数据，确保
每类传感器能够独立启动、观察、记录和自动测试，并保持仿真与未来实体实现使用统一的
Topic、消息、QoS、时间和TF契约。

M3不实现多传感器融合、SLAM、定位、Nav2、目标识别、实体传感器或AI Agent。

## 2. 范围与边界

### 2.1 本阶段范围

- 审查并锁定Gazebo Fortress传感器插件、ROS 2桥接和图像传输依赖；
- 冻结雷达、相机、IMU的安装位置、Frame、更新频率、噪声和数据参数；
- 接入仿真激光雷达并发布`/scan`；
- 接入仿真相机并发布图像与`camera_info`；
- 接入仿真IMU并发布`/imu/data`；
- 复核左右轮仿真编码器方向、累计量、频率及其与里程计的关系；
- 为每类传感器提供独立启动文件、默认参数、接口检查和最小rosbag样本；
- 验证消息类型、频率、时间戳、QoS、Frame、数值范围和基础噪声行为；
- 建立独立节点、Launch、契约和场景自动回归；
- 完成M3正式验收、归档和交接。

### 2.2 本阶段不做

- 不进入M4，不进行底盘与多传感器的完整子系统集成和故障传播测试；
- 不使用`robot_localization`融合IMU与里程计；
- 不实现SLAM、地图、定位、Nav2或自主避障；
- 不实现图像识别、人员感知或目标检测；
- 不连接实体雷达、相机、IMU或底盘；
- 不正式开发或接入AI Agent；
- 不以“Topic存在”代替频率、时间戳、QoS、Frame和数据语义验收。

## 4. 分项验收清单

### 4.1 资源、模型与接口

- [x] 第三方资源记录来源、版本、许可证、兼容性和回退方法；
- [x] 各传感器可单独启停，不依赖SLAM、导航或AI节点；
- [x] Topic、消息、QoS和命名符合M1接口契约；
- [x] `use_sim_time: true`且消息时间戳来自仿真时间；
- [x] 传感器Frame在TF树中唯一、方向正确且无重复发布者；
- [x] 仿真接口不向上层暴露Gazebo插件或版本细节。

### 4.2 激光雷达

- [x] `/scan`消息类型、角度、距离、频率和Frame正确；
- [x] 障碍物距离和方位与Gazebo场景一致；
- [x] 无回波、最小/最大量程和噪声行为明确；
- [x] 时间戳单调，QoS可被预期订阅者发现和接收；
- [x] Gazebo与RViz2人工观察有明确结论。

### 4.3 相机

- [x] 图像与`camera_info`消息类型和Topic正确；
- [x] 分辨率、帧率、编码和相机参数符合配置；
- [x] 图像与相机参数时间戳、Frame对应一致；
- [x] 静态场景内容、方向和视场符合模型；
- [x] 图形界面人工观察有明确结论。

### 4.4 IMU

- [x] `/imu/data`角速度、线加速度、方向和Frame正确；
- [x] 单位、协方差、频率和时间戳符合契约；
- [x] 静止状态输出合理，无持续发散或非有限数值；
- [x] 机器人旋转时角速度符号与TF坐标约定一致；
- [x] 噪声参数和未提供字段的表达方式明确。

### 4.5 编码器、测试与证据

- [x] 左右轮方向、累计位置和更新频率正确；
- [x] 轮累计量与直行、转向和里程计变化关系一致；
- [x] 每类传感器具备独立Launch和自动接口检查；
- [x] M1接口契约与M2底盘回归继续通过；
- [x] 保存配置、命令、日志、最小rosbag和校验哈希；
- [x] 测试不连接实体设备或AI Agent。

## 5. M3完成判定

只有同时满足以下条件，M3才可申请正式验收：

1. M3-W1～M3-W7全部完成并通过对应检查；
2. 雷达、相机、IMU和编码器均可独立启动、停止和重复测试；
3. 消息、Topic、QoS、时间戳、Frame和数据方向满足冻结契约；
4. 雷达距离、相机图像、IMU运动响应和编码器累计量与仿真真值一致；
5. 自动回归通过，必要的Gazebo、RViz2或图像界面人工检查有明确结论；
6. M1接口契约和M2底盘、安全回归未发生退化；
7. 阻塞项关闭，或形成经用户确认的延期与风险处置；
8. 形成M3规划快照、正式验收记录、证据索引和遗留问题；
9. 验收通过后完成`docs/backs/milestones/M3/`归档和M3阶段交接摘要；
10. 经用户明确授权后创建M3基线提交和标签。

M3正式验收通过前不得进入M4。
