# Memo

本目录保存项目备忘、讨论结论、阶段性记录和每日工作Report。

备忘用于解释决策背景、记录当前状态和交接信息，但不替代
`../planning/` 中的正式规划。

每个 M 里程碑正式验收通过后，应在本目录创建一份阶段交接摘要。摘要至少记录：

- 里程碑验收结论和基线提交号；
- 已冻结或确认的环境、接口及工程约束；
- 遗留问题和风险；
- 下一里程碑的允许入口；
- `../backs/milestones/M编号/` 中完整阶段归档的路径。

后续工作默认读取最近的阶段交接摘要；需要完整规划摘录、验证结果或历史证据时，再读取
对应里程碑归档。阶段交接摘要不得复制整套归档材料。

里程碑进行中接续具体工作包时，代理应主动在本目录检索对应`M编号_W编号`验证记录、当前
任务清单和最近相关工作包的经验，不等待用户逐一指定文件位置。若不同工作包的经验表面上
存在差异，应先核对静态/动态、GUI/无GUI、是否含控制器、性能/视觉验收等适用边界，再在
记录中明确继承、扩展或冲突关系。

当用户明确说“今日任务已完成”时，应先确认报告归属今日还是昨日，再按用户确认的日期
在本目录生成Report。每日Report彼此独立、连续保留，不移动到 `backs/`。
