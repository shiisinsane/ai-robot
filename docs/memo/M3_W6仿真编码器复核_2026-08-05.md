# M3-W6仿真编码器复核记录

> 日期：2026年8月5日
> 结论：通过，允许进入M3-W7自动回归与证据

## 1. 实现范围

- 新增`encoder.launch.py`，作为仿真编码器独立启动入口，显式复用M2已验收的安全差速控制链；
- 新增`check_m3_encoder.py`，自动检查左右轮关节名、时间戳、更新频率、累计位置和有限数值；
- 通过受限直行和原地左转，对比轮累计量按轮半径、轮距换算的距离和角度与`/robot/odom`；
- 新增Launch结构及编码器检查覆盖测试，未新增厂商或Gazebo专用公共接口。

编码器继续使用M1冻结的公共`/robot/joint_states`，消息类型为
`sensor_msgs/msg/JointState`，QoS为`state_stream`。左右轮累计位置单位为弧度、速度单位为
弧度每秒。Gazebo控制状态以双精度连续关节位置表达，不额外模拟实体编码器离散脉冲分辨率；
实体编码器计数和量化误差不属于M3范围。

## 2. 自动验证结果

验证环境使用独立`ROS_DOMAIN_ID=86`和`IGN_PARTITION=m3_w6_encoder_20260805`，无GUI运行
Gazebo Fortress。检查节点只发送受限前进和左转命令，正常与异常退出路径均发布零速度。

| 指标 | 结果 | 判定 |
|---|---:|---|
| 编码器更新频率 | 100.000 Hz | 高于20 Hz最低要求 |
| 直行左轮累计量 | +3.772 rad | 前进为正 |
| 直行右轮累计量 | +3.772 rad | 前进为正，左右一致 |
| 编码器折算直行距离 | 0.283 m | 与里程计一致 |
| 里程计直行距离 | 0.281 m | 差值0.002 m |
| 左转左轮累计量 | -1.828 rad | 逆时针时左轮为负 |
| 左转右轮累计量 | +2.284 rad | 逆时针时右轮为正 |
| 编码器折算左转角度 | +0.907 rad | 与里程计方向、数值一致 |
| 里程计左转角度 | +0.901 rad | 差值0.006 rad |

轮累计位置均为有限数值，消息时间戳严格递增。直行距离按
`r × (Δleft + Δright) / 2`计算；转角按`r × (Δright - Δleft) / wheel_separation`
计算，其中轮半径为`0.075 m`、轮距为`0.34 m`。

原地左转左右累计量绝对值存在短时差异，是受M2安全过滤器角加速度限制、命令建立和停止
过渡以及采样边界影响；由同一对轮累计量折算的角度与里程计仅相差`0.006 rad`，方向和累计
语义正确。
