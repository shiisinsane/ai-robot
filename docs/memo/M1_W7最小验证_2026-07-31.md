# M1-W7最小录制与回放验证

**验证日期：** 2026年7月31日

**基线提交：** `2677629`（验证W7未提交改动前的`HEAD`）

**环境：** Ubuntu 22.04、ROS 2 Humble、rosbag2 0.15.16、SQLite3

**安全边界：** 仅使用无运动能力的`std_msgs/msg/String`测试Topic，不启动底盘、Gazebo、
导航、实体设备或AI Agent。

## 1. 录制

使用独立`ROS_DOMAIN_ID=65`录制`/w7/status`，发布8条内容为`w7-evidence`的消息，再以
`SIGINT`正常停止录制。

结果：

- 存储文件：`bag_0.db3`；
- 存储类型：`sqlite3`；
- 消息类型：`std_msgs/msg/String`；
- 消息数：8；
- 持续时间：`0.700325612 s`；
- 数据文件大小：24576字节；
- `metadata.yaml`大小：957字节。

## 2. 完整性检查

执行：

```bash
python3 scripts/check_rosbag.py <临时bag目录> \
  --required-topic /w7/status
```

结果通过：

- `metadata.yaml`存在；
- 总消息数和持续时间大于零；
- `/w7/status`存在；
- 必需Topic至少包含一条消息。

## 3. 回放

使用独立`ROS_DOMAIN_ID=66`，将：

```text
/w7/status → /w7/replayed
```

重映射回放。独立订阅者通过`ros2 topic echo --no-daemon --once`收到：

```text
data: w7-evidence
```

首次订阅尝试因受限环境不允许ROS CLI守护进程套接字而失败；改用CLI正式支持的
`--no-daemon`模式后通过。该限制不影响rosbag内容、检查结果或DDS回放。
