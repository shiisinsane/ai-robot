# M2本体参数基线

> 版本：M2-W2首版
> 状态：仿真首版
> 机器配置：`../config/common/robot_model.yaml`
> 边界：本规范定义M2仿真初值，不代表实体机器人尺寸或采购结论。

## 1. 目标

在编写URDF/Xacro前冻结首版几何、质量、惯量、关节、Frame和运动限制，使模型、控制器、
测试和证据引用同一份机器配置。实体阶段允许用实测值替换物理参数，但公共接口和Frame
语义不得静默改变。

## 2. 首版参数

| 类别 | 参数 | 数值 |
|---|---|---|
| 底盘 | 长×宽×高 | `0.45 × 0.28 × 0.16 m` |
| 底盘 | 质量 | `10.0 kg` |
| 驱动轮 | 半径/宽度 | `0.075 / 0.035 m` |
| 驱动轮 | 轮距 | `0.34 m` |
| 驱动轮 | 单轮质量 | `0.6 kg` |
| 支撑 | 前后两个球形支撑 | 半径`0.03 m`，单个`0.15 kg` |
| 整机 | 参数质量合计 | `11.5 kg` |
| 运动 | 最大线速度/加速度 | `0.6 m/s` / `1.0 m/s²` |
| 运动 | 最大角速度/加速度 | `1.5 rad/s` / `3.0 rad/s²` |
| 控制 | 更新/里程计频率 | `100 / 50 Hz` |
| 安全 | 命令超时 | `0.2 s` |

惯量采用底盘长方体、轮子圆柱体和支撑球的解析初值，具体数值保存在机器配置中。W3生成
URDF时不得重新手工计算另一套惯量；若物理参数变化，应先修改机器配置并重新运行校验。

## 3. Link、Joint与Frame

| 对象 | 名称或关系 | 约束 |
|---|---|---|
| 机体 | `base_link` | M1公共机体Frame，离地`0.12 m` |
| 地面投影 | `base_link → base_footprint` | 固定辅助Frame，不插入`odom`主链 |
| 左轮 | `left_wheel_link` / `left_wheel_joint` | 位于`y=+0.17 m`，轴向`+y` |
| 右轮 | `right_wheel_link` / `right_wheel_joint` | 位于`y=-0.17 m`，轴向`+y` |
| 前支撑 | `front_caster_link` / `front_caster_joint` | 固定球形碰撞体 |
| 后支撑 | `rear_caster_link` / `rear_caster_joint` | 固定球形碰撞体 |
| 里程计主链 | `odom → base_link` | 由差速控制器唯一发布 |

`base_footprint`只用于地面投影和后续可视化兼容，不能把主链改成
`odom → base_footprint → base_link`，否则会破坏M1冻结契约。

## 4. 控制器输入

- 控制器名称：`diff_drive_base_controller`；
- 左右轮使用位置反馈和速度命令接口；
- `open_loop: false`，里程计必须来自轮反馈；
- `use_stamped_vel: false`，用于适配M1的`geometry_msgs/msg/Twist`；
- `cmd_vel_timeout: 0.2`，不得采用上游默认`0.5 s`；
- `enable_odom_tf: true`，并保证只有一个`odom → base_link`发布者；
- 仿真统一使用`use_sim_time: true`和全局`/clock`。

## 5. 后续验证与调整

W3必须验证Xacro展开、Link/Joint完整性、惯量和TF静态关系。W4～W7必须在Fortress中检查
模型接触、漂浮、翻倒、轮滑、方向、里程计、限速和超时停车。以下情况触发参数重审：

- 模型静止时明显下沉、抖动或翻倒；
- 轮滑导致里程计误差不可接受；
- 支撑球产生过度摩擦或四点接触不稳定；
- 速度和加速度使控制不稳定；
- 获得实体底盘实测尺寸、质量、重心或惯量。

参数调整必须同步更新机器配置、本文、Xacro输入和测试，不允许只在Gazebo或控制器YAML中
局部修改。
