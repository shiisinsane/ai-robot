## 1. 统一入口

新增统一入口：

```bash
./scripts/run_m4_regression.sh
```

入口先执行全仓构建和测试，再连续运行两轮隔离无GUI整机回归。每轮使用独立
`ROS_DOMAIN_ID`、`IGN_PARTITION`、ROS日志目录和Gazebo目录，覆盖：

- 30秒实时因子、CPU、RSS、Topic频率、QoS、时间戳和TF审计；
- 相机原始/校正图像的规格、时间戳、Frame和延迟；
- 雷达扫描、运动语义和`odom → base_link → laser_link`；
- 编码器与IMU融合、直行、左转、协方差和TF一致性；
- 命令超时、非法命令、停车锁存和条件清除；
- 9个整机公共Topic的最小rosbag录制、完整性检查及另一ROS Domain中的安全回放。

两轮结束后，入口另行启动雷达断流和相机监测断流场景，分别验证停车级故障与告警级故障。
任一构建、测试、Launch、运行检查、rosbag、回放或清理失败都会返回非零退出码。
