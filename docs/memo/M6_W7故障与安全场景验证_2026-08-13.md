# M6-W7 故障与安全场景验证记录

> 日期：2026年8月13日
> 结论：通过，允许进入M6-W8重复执行与性能。

## 1. 完成内容

- 新增`check_m6_fault_scenarios.py`，统一验证输入、不可达、感知断流和安全断流；
- 地图外、非法Frame、非有限坐标均在调用公共导航Action前拒绝；
- 障碍物内部目标通过任务层稳定传播为`ERROR_NAVIGATION_FAILED`；
- 相机断流不触发停车，但到点感知拒绝旧图像并返回`ERROR_SENSOR_STALE`；
- 雷达、IMU和融合里程计断流触发M4安全停车锁存，任务返回`ERROR_SAFETY_STOP`；
- AMCL定位断流由M5定位TF看门狗失败关闭，任务返回`ERROR_NAVIGATION_FAILED`；
- 每项故障结束后确认公共导航Action无活动目标；停车级故障检查非零安全命令收尾时延；
- 任务管理器在下游Action结束后再次检查安全停车和用户取消，保证安全优先级不因异步终态
  竞态被降级为普通导航失败。

## 2. 端到端结果

在隔离ROS Domain 222启动无GUI Gazebo、M5导航栈和M6任务管理器：

| 场景 | 任务结果 | 收尾结果 |
|---|---|---|
| 地图外、非法Frame、非有限值 | 3/3 `ERROR_INVALID_TARGET` | 未进入导航，无运动命令 |
| 障碍内目标 | `ERROR_NAVIGATION_FAILED` | 下游Action结束 |
| 相机断流 | `ERROR_SENSOR_STALE` | 未错误升级为安全停车 |
| 雷达断流 | `ERROR_SAFETY_STOP` | 最后非零安全命令0.262 s |
| IMU断流 | `ERROR_SAFETY_STOP` | 最后非零安全命令0.178 s |
| 融合里程计断流 | `ERROR_SAFETY_STOP` | 最后非零安全命令0.150 s |
| AMCL定位断流 | `ERROR_NAVIGATION_FAILED` | 定位看门狗关闭，下游Action结束 |

雷达、IMU和里程计均满足停车级故障不超过`0.5 s`的门限。相机是W2冻结的感知可用性输入，
不是停车级输入，因此保持任务感知失败而不激活安全停车。定位丢失由M5导航适配层处理，并无
对应M4停车锁存错误码，故不伪装为`ERROR_SAFETY_STOP`。
