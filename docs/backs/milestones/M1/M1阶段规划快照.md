## 2. 阶段目标快照

M1为M2～M6仿真机器人开发建立可追踪的资源准入规则、仿真与实体统一的公共接口约束、
可复用测试骨架以及rosbag和测试证据规则。M1不实现完整机器人能力。

## 3. 阶段范围快照

1. 建立对象、资源、仿真与实体替换关系和测试方法矩阵；
2. 建立第三方资源准入流程并确认Gazebo技术路线；
3. 定义Topic、Service、Action、消息、命名和参数规范；
4. 定义QoS、时间、超时和`map → odom → base_link → sensor_link`责任链；
5. 建立单元、节点、Launch、契约和仿真测试骨架；
6. 建立rosbag录制、回放、完整性检查和证据清单规则；
7. 完成正式验收、归档和阶段交接。

## 4. 冻结边界

- M1接口版本为`m1.v1`；
- Gazebo Fortress 6.18.0作为M2～M6主线，Gazebo Classic仅作临时回退；
- 仿真与实体保持统一公共接口、QoS、时间和TF语义；
- G1通过前不进入实体机器人开发；
- G2通过前不正式开发或接入AI Agent；
- 未经明确授权不执行实体运动、硬件写入或安全回路修改。
