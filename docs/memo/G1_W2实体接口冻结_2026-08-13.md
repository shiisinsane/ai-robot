# G1-W2实体接口冻结记录

> 日期：2026年8月13日
> 结论：通过
> 机器可读清单：`../../config/common/g1_entity_interface_freeze.yaml`

## 1. 冻结结论

实体机器人必须保持当前`m1.v2`公共接口、时间、TF、QoS和任务语义不变。仿真插件可替换为
厂商驱动、MCU桥接或实体适配器，但替换只能发生在适配层以下，Nav2、任务管理器和应用节点
不得通过设备厂商私有接口工作。

本冻结是G1候选审查基线，不表示任何具体硬件已经选定，也不授权连接或控制实体设备。

## 2. 公共接口冻结

默认命名空间为`/robot`，节点内部使用相对名称；公共名称不得包含`sim`、`real`或厂商名。

### Topic

| 接口 | 类型 | 状态与语义 |
|---|---|---|
| `cmd_vel` | `geometry_msgs/msg/Twist` | 必需；应用唯一速度入口，归安全监督器所有 |
| `odom` | `nav_msgs/msg/Odometry` | 必需；融合或规范化后的公共里程计 |
| `joint_states` | `sensor_msgs/msg/JointState` | 必需；轮关节名称、方向和单位保持一致 |
| `battery_state` | `sensor_msgs/msg/BatteryState` | 必需；实体由MCU或电源管理适配 |
| `scan` | `sensor_msgs/msg/LaserScan` | 必需；平面雷达、`laser_link`、SI单位 |
| `imu/data` | `sensor_msgs/msg/Imu` | 必需；ENU/REP-103语义、协方差有效 |
| `camera/color/image_raw` | `sensor_msgs/msg/Image` | 必需；原始RGB图像 |
| `camera/color/camera_info` | `sensor_msgs/msg/CameraInfo` | 必需；与图像时间和Frame匹配 |
| `map` | `nav_msgs/msg/OccupancyGrid` | 必需；地图事件发布、Transient Local |
| `initialpose` | `geometry_msgs/msg/PoseWithCovarianceStamped` | 必需；定位初始位姿输入 |
| `pose` | `geometry_msgs/msg/PoseWithCovarianceStamped` | 必需；公共全局位姿 |
| `diagnostics` | `diagnostic_msgs/msg/DiagnosticArray` | 必需；设备、适配、定位、导航和安全诊断汇总 |
| `safety/stop_active` | `std_msgs/msg/Bool` | 必需；停车状态，超时按停车激活处理 |
| `camera/depth/image_raw` | `sensor_msgs/msg/Image` | 条件启用；只有选定深度相机时要求 |
| `camera/depth/camera_info` | `sensor_msgs/msg/CameraInfo` | 条件启用；与深度图配套 |

完整QoS、最低频率和超时以`config/common/interface_contract.yaml`为唯一来源，W2不复制第二份
可能漂移的数值表。人员检测、综合状态和详细安全状态继续延后，不在G1中伪造接口。

### Service与Action

| 类别 | 接口 | 类型 |
|---|---|---|
| Service | `map/save_map` | `nav2_msgs/srv/SaveMap` |
| Service | `safety/clear_faults` | `std_srvs/srv/Trigger` |
| Action | `navigation/navigate_to_pose` | `nav2_msgs/action/NavigateToPose` |
| Action | `navigation/follow_waypoints` | `nav2_msgs/action/FollowWaypoints` |
| Action | `task/execute` | `robot_interfaces/action/ExecuteRobotTask` |

`task/execute`继续遵守`m6.task.v1`：单活动任务、并发拒绝、8个状态、13个错误码、安全优先，
任务终态不得遗留活动下游导航目标。

## 3. 时间与TF冻结

- 仿真使用`use_sim_time=true`和唯一`/clock`；实体必须`use_sim_time=false`；
- 消息时间戳使用ROS时间，安全和超时看门狗使用steady clock；拒绝零时间戳并处理时钟回跳；
- 坐标使用SI、右手系，`x`向前、`y`向左、`z`向上，逆时针为正航向；
- `map→odom`仅由当前SLAM或定位节点发布，二者不得同时拥有；
- `odom→base_link`仅由公共状态估计器发布，底盘驱动不得重复发布；
- `base_link`到雷达、相机和IMU Frame由`robot_state_publisher`唯一发布；
- 实体传感器至少保持`laser_link`、`camera_color_link`、`camera_color_optical_frame`和
  `imu_link`公共Frame名称。

根Link惯量提示的处置决定为：G1不因无功能影响修改已验收公共TF；实体URDF设计若引入虚拟
根Link，必须保持`base_link`及全部公共TF关系兼容并重跑模型、TF和导航回归。

## 4. 设备适配边界

| 对象 | 适配层以下允许变化 | 适配后必须提供 |
|---|---|---|
| 底盘/MCU | 串口、CAN、厂商速度协议、原始编码器和里程计 | `controller_cmd_vel`输入、规范化原始里程计、`joint_states` |
| 雷达 | 厂商点云/扫描Topic、角度顺序和设备时间 | `/robot/scan`及冻结QoS、Frame、时间和SI单位 |
| 相机 | USB/网络驱动、像素格式、厂商图像与内参Topic | 公共RGB图像、内参和校正图像 |
| IMU | 串口/CAN/USB协议、NED或厂商坐标、设备时间 | `/robot/imu/data`的ENU语义、协方差和时间戳 |
| 电池/电源 | MCU寄存器、BMS协议和厂商状态码 | `/robot/battery_state`和诊断 |

`/robot/internal/*`、`/robot/safety_cmd_vel`和`/robot/controller_cmd_vel`属于内部集成接口，不是
应用API。具体实体私有名称可随驱动变化，但必须由Launch/适配器封装，任务和业务节点不得订阅。

## 5. 安全命令链冻结

```text
Nav2/授权操作源
→ /robot/cmd_vel（SafetySupervisor唯一消费与裁决）
→ /robot/safety_cmd_vel
→ 有限值、速度和加速度过滤
→ /robot/controller_cmd_vel
→ 实体底盘适配器/控制器
```

- 禁止Nav2、任务管理器或遥控节点直接访问实体控制器；
- ROS安全监督不能替代硬件急停；实体急停必须独立于ROS和上位机；
- 命令、里程计、IMU和雷达超时继续锁存停车；相机断流保持告警/任务感知失败语义；
- 清除故障必须零命令、停车级输入全部新鲜并显式调用Service；
- 驱动失联必须锁存停车并使活动任务失败关闭。

硬件急停回路、电机使能、制动和失联实现细节转G1-W5冻结。

## 6. 生命周期责任冻结

实体启动顺序为：硬件传输与驱动 → 设备适配器与机器人描述 → 状态估计与安全监督 → 地图和
定位 → Nav2规划控制 → 任务管理器。进入任务就绪前必须确认必需驱动健康、公共Topic新鲜、
TF发布者唯一且安全状态明确。

M6遗留的`planner_server`偶发inactive不能作为实体正常启动方式接受。G1冻结要求实体部署中
生命周期转换可观测、失败关闭且不依赖无记录的人工操作；具体部署依赖在W3审查，最终在G1-W6
列为准入复核项。

## 7. 兼容性与变更规则

- 允许：适配层以下硬件参数、设备路径和厂商协议变化；公共接口兼容新增并附测试和版本说明；
- 禁止：未经重新准入改变公共名称、消息类型、QoS、Frame、单位、方向、时间或安全语义；
- 任何破坏性变更必须提升接口版本、更新仿真适配、重跑M1～M6相应回归并重新审查G1；
- 外部精度门槛保持`0.15 m / 0.15 rad`，不得以实体噪声为由静默放宽。

## 8. 验证结果与下一入口

机器契约测试确认冻结清单覆盖`m1.v2`全部15个Topic、2个Service和3个Action，且保留实体时间、
TF唯一发布者和禁止控制旁路规则。

下一入口为G1-W3“硬件与驱动候选审查”。W3依据本清单逐项判断候选是否能通过适配器提供冻结
接口；本记录不连接实体设备，也不构成采购决定。
