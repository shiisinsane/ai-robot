# M5已知遗留问题

以下事项不阻止M5验收，但必须在对应后续阶段继续处理。

| 遗留事项 | 风险 | 后续入口和关闭条件 |
|---|---|---|
| 个别短路线导航会进入恢复流程，单次耗时可超过90秒 | 综合任务中的超时预算和用户体验可能受影响 | M6按能力任务冻结端到端超时，并在重复场景中验证 |
| 根Link带惯量仍会产生KDL提示 | 某些新增KDL使用方可能不能表达根Link惯量 | M6引入任务或感知组合前评估虚拟根Link，出现功能影响时修复 |
| W10原始证据只存于本地`artifacts/` | 本地删除后只能依靠摘要和哈希追溯 | M6前确定大型证据的外部存储与保留策略 |
| W10调试阶段的失败证据目录仍保留 | 占用额外本地磁盘，但有定位回归波动的价值 | 用户确认不再需要后再执行可恢复清理 |
| M5修改和归档尚未形成Git提交 | 当前正式验收尾项位于未提交工作树 | 用户另行授权提交后补充最终基线；标签仍需单独授权 |

M6、G1、G2和实体安全边界继续有效，不得用上述遗留事项绕过阶段门。
