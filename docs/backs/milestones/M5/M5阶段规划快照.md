## 2. 阶段目标快照

在M4整机运动、感知、状态估计和安全链之上，建立二维SLAM、地图保存与重载、地图定位、
Nav2全局规划、局部控制与避障、恢复和取消能力；通过重复到点、障碍、定位初始偏差、不可达、
超时和故障注入证明导航系统可重复、安全且可追溯。

## 3. 阶段范围快照

1. 完成SLAM、定位和Nav2成熟资源准入，冻结公共接口、TF、安全命令链和性能门限；
2. 建立受监督SLAM建图、地图保存守卫和独立重载能力；
3. 建立Map Server与AMCL定位，验证初始偏差收敛和定位稳定性；
4. 建立Nav2全局规划，验证可达、地图外和障碍内目标；
5. 建立局部控制与公共导航Action，验证静态障碍绕行和终点精度；
6. 建立临时障碍重规划、受限恢复、任务取消和不可达失败反馈；
7. 对雷达、IMU、融合里程计和定位断流实施导航安全验证；
8. 验证重复导航成功率、精度、耗时、实时因子、CPU、RSS和数据频率；
9. 建立统一自动回归，形成最小rosbag、隔离回放、日志、配置快照和SHA-256；
10. 完成正式验收、归档和阶段交接。

## 4. 冻结边界

- 公共导航Action为`/robot/navigation/navigate_to_pose`，支持成功、失败和取消状态；
- `map → odom`由SLAM或AMCL按运行模式唯一负责，`odom → base_link`继续由EKF负责；
- Nav2速度命令只能进入M4公共`/robot/cmd_vel`安全监督链，不存在控制旁路；
- 停车级传感器断流必须锁存安全停车并使导航Action失败关闭；
- 导航重复成功率为5/5，终点位置与角度误差均不得超过`0.15`；
- M5不包含任务管理器、实体机器人、视觉/三维SLAM、目标识别、语义导航或AI Agent；
- M6必须由用户另行明确启动，G1和G2阶段门继续有效。
