# M2“仿真本体与底盘单元”任务与验收清单

> 启动日期：2026年8月3日
> 依据：`../planning/AI机器人开发项目计划_v1.8.md`、
> `../planning/ROS2机器人开发规划_v1.4.md`
> 输入基线：M1正式归档`../backs/milestones/M1/`、接口版本`m1.v1`
> 定位：M2执行与验收跟踪清单，不替代正式规划。

## 1. 阶段目标

建立可复用的URDF/Xacro差速机器人本体，在Gazebo Fortress中接入`ros2_control`和
`diff_drive_controller`，独立验证速度命令、轮状态、里程计、TF、限速、命令超时和停车。
M2不实现传感器、SLAM、定位、Nav2、实体底盘或AI Agent。

## 2. 范围与边界

### 2.1 本阶段范围

- 锁定机器人模型、状态发布、Gazebo控制和差速控制依赖；
- 定义首版仿真几何、质量、惯量、关节和碰撞参数；
- 建立URDF/Xacro模型、差速轮关节和TF；
- 在Gazebo Fortress中加载模型和`gz_ros2_control`；
- 接入`joint_state_broadcaster`和`diff_drive_controller`；
- 适配M1冻结的`/robot/cmd_vel`、`/robot/odom`、`/robot/joint_states`及TF契约；
- 验证前进、后退、原地转向、停车、里程计方向、限速和命令超时；
- 建立模型、节点、Launch、契约和仿真场景自动测试；
- 保存配置、日志、测试结果和最小rosbag证据；
- 完成M2正式验收、归档和交接。

### 2.2 本阶段不做

- 不进入M3，不接入雷达、相机或IMU仿真；
- 不实现SLAM、定位、Nav2或人员感知；
- 不连接实体底盘，不执行硬件写入或实体运动；
- 不正式开发或接入AI Agent；
- 不绕过安全和命令仲裁边界直接形成实体控制链；
- 不以Gazebo中“能动”代替里程计、TF、超时和重复性验收。

## 4. 分项验收清单

### 4.1 资源与模型

- [x] 第三方资源记录来源、版本、许可证、兼容性和回退方法；
- [x] 模型使用Xacro组织并可在无Gazebo环境下解析；
- [x] Link、Joint、碰撞体、惯量和Frame命名符合M1契约；
- [x] 左右轮轴向、旋转正方向、轮径和轮距具有唯一参数来源；
- [x] 模型无明显穿透、漂浮、翻倒或异常抖动。

### 4.2 Gazebo与控制

- [x] Fortress无界面启动、模型生成、停止和重复启动通过；
- [x] 仿真统一使用`/clock`和`use_sim_time: true`；
- [x] `gz_ros2_control`成功加载且控制器生命周期状态明确；
- [x] `joint_state_broadcaster`和差速控制器按确定顺序激活；
- [x] 上层接口不包含Gazebo版本、`sim`或具体控制插件名称。

### 4.3 运动、里程计与TF

- [ ] 前进和后退方向正确；
- [ ] 左右原地转向方向正确；
- [ ] 零速度命令能够停车；
- [ ] `/robot/cmd_vel`、轮速、`/robot/odom`和TF方向一致；
- [ ] `odom → base_link`发布者唯一，更新频率和超时满足M1契约；
- [ ] `/robot/joint_states`名称、方向和频率正确；
- [ ] 速度和加速度限制生效；
- [ ] 超过`0.2 s`无合法命令后停车；
- [ ] 非法、过大或非有限数值命令被拒绝或安全处理。

### 4.4 测试与证据

- [ ] 普通模型参数或计算逻辑具备离线单元测试；
- [ ] URDF/Xacro解析、惯量、Joint和Frame具备模型测试；
- [ ] 控制器启动、停止和生命周期具备Launch测试；
- [ ] M1公共接口、QoS、时间和TF契约检查继续通过；
- [ ] 前进、后退、转向、停车、限速和超时场景可自动重复；
- [ ] 保存版本、配置、命令、结果、日志和最小rosbag证据；
- [ ] 测试不连接实体设备或AI Agent。

## 5. M2完成判定

只有同时满足以下条件，M2才可申请正式验收：

1. M2-W1～M2-W8全部完成并通过对应检查；
2. 前进、后退、原地转向和停车方向正确且可重复；
3. 速度命令、轮状态、里程计和TF方向一致；
4. 模型、控制器、QoS、时间、命名和TF满足M1冻结契约；
5. 速度限制、命令超时停车和异常输入处理通过；
6. 自动检查通过，人工模型审查有明确结论；
7. 阻塞项关闭，或形成经用户确认的延期与风险处置；
8. 形成M2规划快照、正式验收记录、证据索引和遗留问题；
9. 验收通过后完成`docs/backs/milestones/M2/`归档和M2阶段交接摘要；
10. 经用户明确授权后创建M2基线标签。

M2正式验收通过前不得进入M3。
