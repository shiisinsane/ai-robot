## 2. 阶段目标快照

建立可复用的URDF/Xacro差速机器人本体，在Gazebo Fortress中接入`ros2_control`和
`diff_drive_controller`，独立验证速度命令、轮状态、里程计、TF、限速、命令超时和
停车，并形成可重复的自动回归与证据。

## 3. 阶段范围快照

1. 锁定模型、状态发布、Gazebo控制和差速控制依赖；
2. 冻结仿真几何、质量、惯量、轮距、轮径、关节、Frame和运动限制；
3. 建立URDF/Xacro模型及Gazebo Fortress加载流程；
4. 接入`gz_ros2_control`、关节状态广播器和差速控制器；
5. 适配M1冻结的速度、里程计、关节状态和TF契约；
6. 验证运动方向、停车、里程计、TF、限速、超时和异常输入恢复；
7. 建立自动场景、最小rosbag、安全回放和证据哈希；
8. 完成正式验收、归档和阶段交接。

## 4. 冻结边界

- 机器人模型版本为`m2.v1`；
- 公共速度接口保持`/robot/cmd_vel`，控制器私有输入为`/robot/controller_cmd_vel`；
- 线速度、线加速度、角速度和角加速度上限分别为`0.6 m/s`、`1.0 m/s²`、
  `1.5 rad/s`和`3.0 rad/s²`；
- 命令超时为`0.2 s`，超时后按加速度限制停车；
- 主TF保持`odom → base_link`；
- M2不包含传感器、SLAM、定位、Nav2、实体机器人或AI Agent；
- G1通过前不进入实体机器人开发，G2通过前不正式开发或接入AI Agent。
