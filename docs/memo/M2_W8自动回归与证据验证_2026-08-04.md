## 1. 自动回归入口

统一入口：

```bash
./scripts/run_m2_regression.sh --runs 2
```

每轮自动执行：

1. 分配独立`ROS_DOMAIN_ID`和Gazebo Transport分区；
2. 启动Fortress、模型、状态发布、安全过滤节点和控制器；
3. 等待两个控制器达到`active`；
4. 检查`/robot/cmd_vel → 安全过滤 → /robot/controller_cmd_vel → 控制器`运行图；
5. 自动验证前进、后退、左右转向、零速停车、轮状态及`odom → base_link`；
6. 自动验证速度、加速度、`0.2 s`超时、NaN、正负Infinity和异常恢复；
7. 录制并检查最小rosbag，计算文件大小和SHA-256；
8. 停止rosbag和Launch，下一轮使用全新隔离环境。

任一检查失败时入口返回非零退出码，并在证据目录保留摘要和日志。
