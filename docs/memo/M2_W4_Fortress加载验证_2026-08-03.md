# M2-W4 Fortress加载验证记录

> 验证日期：2026年8月3日  
> 阶段：M2-W4  
> 结论：通过，允许进入M2-W5差速控制接入

## 1. 验证范围

本次仅验证Gazebo Fortress无界面加载，不加载`gz_ros2_control`，不启动控制器，不发布
`/robot/cmd_vel`，不连接实体设备。验证对象包括仿真世界、模型生成、`/clock`、静止接触、
启动停止和离线资源契约。

## 2. 交付物

- `src/robot_core/ai_robot_sim/`：独立仿真软件包；
- `worlds/m2_empty.sdf`：包含重力、地面、物理、用户命令和场景广播系统的最小世界；
- `launch/fortress.launch.py`：Fortress 6服务端、状态发布、时钟桥接和延迟生成流程；
- `scripts/check_sim_assets.py`：W4资源边界离线检查；
- `tests/simulation/test_fortress_assets.py`：仓库级仿真资源契约测试。

## 3. 环境与关键命令

- Gazebo Fortress：`ign gazebo 6.18.0`；
- ROS/Gazebo集成：`ros_gz_sim 0.244.25`、`ros_gz_bridge 0.244.25`；
- 构建：`colcon build --packages-select ai_robot_description ai_robot_sim --symlink-install`；
- 包测试：`colcon test --packages-select ai_robot_sim`；
- 运行：`ros2 launch ai_robot_sim fortress.launch.py`；
- 时间检查：`ros2 topic echo /clock --once`；
- 位姿检查：`ign topic -e -t /world/m2_empty/pose/info -n 1`。

## 5. 已知说明

`robot_state_publisher`仍会提示KDL不支持根Link带惯量。这是W3模型以`base_link`作为根节点
且包含物理惯量时的已知提示，不影响URDF解析、TF发布或本次Gazebo物理加载。为保持M1冻结的
主TF契约，本工作包不额外引入改变主链语义的根Frame；后续若需要消除此提示，应单独评估
接口兼容性。

W4的模型静止稳定结论同时具有无界面位姿数据和用户GUI人工观察证据。小车始终静止符合
W4边界：本工作包未接入控制器或运动命令。
