## 2. 冻结结论

- TF主链为`map → odom → base_link`。建图模式由`slam_toolbox`独占`map → odom`，定位模式
  由AMCL独占；两者不得同时发布。`odom → base_link`继续由M4状态估计器独占；
- 公共导航输入输出保持M1接口：`/robot/scan`、`/robot/odom`、`/robot/map`、
  `/robot/initialpose`、`/robot/pose`、地图保存Service和两个导航Action；
- Nav2速度只能发送到`/robot/cmd_vel`，由M4安全监督器处理后再进入控制器，禁止访问
  `/robot/controller_cmd_vel`；
- 导航初始限速冻结为线速度`0.35 m/s`、角速度`1.0 rad/s`，低于M2底盘硬限制；
- 雷达、里程计、IMU或定位丢失必须取消任务并受控停车；地图缺失、不可达和障碍阻塞均有
  明确失败关闭或重规划策略；
- W9验收基线为5次重复目标全部成功、位置误差不超过`0.15 m`、取消到停车不超过
  `0.5 s`、实时因子不低于`0.5`、CPU不超过`500%`、RSS不超过`2560 MiB`。
