# G1已知遗留问题

| 遗留事项 | 风险 | M7关闭条件 |
|---|---|---|
| 预算、采购地区和用途约束未输入 | 无法冻结最终料号和供应链 | 用户确认需求，形成具体BOM和替代料 |
| 质量、载荷、速度、坡度和轮系参数未知 | 无法核算电机、驱动和编码器 | 完成运动学、扭矩、制动和分辨率预算 |
| 电池、上位机、端口和机械空间未知 | 无法完成实际电源、带宽、热和安装核算 | 选定候选并用数据手册与台架实测关闭 |
| 硬件驱动尚未做Humble PoC | 官方说明不等于目标平台运行通过 | 固定版本并完成离线构建、启动和接口验证 |
| 急停和安全回路只有设计原则 | 未经专业评估不得施工或运动 | 完成适用法规、风险评估、原理图和专业审查 |
| `planner_server`启动偶发恢复 | 实体部署启动确定性不足 | 固化启动依赖并证明无需无记录人工干预 |
| AMCL和实体传感参数未标定 | 实体精度和耗时未知 | M7冻结方案，M8～M10实测且不放宽外部门槛 |
| 大型证据存储介质和期限未落地 | 实体证据可能丢失 | M7确定受控存储、备份、容量和保留周期 |

这些事项不阻止进入M7，因为M7的目的正是完成资源定型和安全准备；在对应关闭条件完成前，
不得进入相关实体上电或运动门禁。
