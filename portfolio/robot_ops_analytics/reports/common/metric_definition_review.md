# W1 指标口径评审记录

> 日期：2026-08-19  
> 指标版本：roa-metrics-v1.0  
> 结论：W1 通过，W2 待启动

## 1. 已冻结内容

- 业务问题：在安全护栏下提高每机器人单位仿真时间内的有效完成任务数。
- 分析主粒度：一次任务执行；重试生成新的 `task_id` 并关联原请求。
- 北极星指标：每机器人单位仿真时间有效完成任务数。
- 核心指标：任务完成率、准时完成率、任务周期、恢复/介入率和路径效率。
- 诊断指标：拒绝率、取消率和分阶段失败率。
- 护栏指标：最小障碍距离、安全停车率、超速任务率、传感器过期任务率。
- 数据质量护栏：有效遥测覆盖率。
- 正常运行和故障注入必须分群报告。
- 拒绝、取消和失败不得静默合并。
- 效率指标必须与安全护栏共同报告。

## 2. 关键口径决策

### 2.1 北极星指标分母

分母采用每台机器人的有效仿真运行小时，而不是整场实验的墙钟时间。环境启动、关闭、仿真时钟
停滞和污染区间不计入；同一机器人重叠的有效窗口先合并再求和，避免重复计算机器人小时。

### 2.2 完成率的任务总体

任务完成率只在有效且被系统接受的执行尝试中计算。拒绝率单独报告，避免通过拒绝困难任务抬高
完成率。取消率也单独报告，不计入失败率分子。

### 2.3 故障注入

故障注入用于覆盖失败类别和训练风险模型，但其构造比例不代表自然运营故障率。所有报表必须先
分别展示自然运行与故障注入结果，合并结果只能用于明确标注的算法评估。

### 2.4 时间口径

正式任务耗时使用 ROS 仿真时间。墙钟时间只用于诊断环境性能，不能与仿真时间混合。时间戳
倒退、跨时钟关联或 `/clock` 停滞会使实验或记录进入质量检查。

### 2.5 SLA

当前没有足够基线数据，`task_sla_sec` 不填写计划值。W4 基线实验产生候选分布后，应在查看
策略实验结果之前冻结 SLA。冻结前只允许探索性展示候选阈值，不输出正式准时完成率。

### 2.6 人工介入

当前项目没有真实人工操作事件，因此指标正式名称为“恢复/介入率”。只有后续明确记录操作者、
时间、原因和动作，才能拆分并使用“模拟人工介入率”；不得写成真实人工团队介入率。
