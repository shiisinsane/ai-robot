# M2-W5差速控制接入验证记录

> 验证日期：2026年8月3日  
> 结论：通过，允许进入M2-W6

## 完成内容

- 模型增加默认关闭、仿真启动时显式启用的`gz_ros2_control`配置；
- 左右轮提供速度命令、位置和速度状态接口；
- 新增控制器配置，参数映射W2基线；
- 控制器按模型生成、`joint_state_broadcaster`、`diff_drive_base_controller`顺序启动；
- 控制话题适配为M1公共接口，不暴露仿真实现名称。

```bash

```

## 已知说明与下一步

控制器更新周期为10 ms，Gazebo物理步长为1 ms，日志中的周期差异提示符合当前100 Hz控制
基线，不构成错误。W5只证明控制链能够加载、激活和关闭；前进、后退、原地转向、停车、
轮状态、里程计和TF方向一致性将在W6验证。
