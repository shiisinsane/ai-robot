# M2-W7限速与超时安全验证记录

> 验证日期：2026年8月4日
> 结论：通过，允许进入M2-W8

## 1. 验证范围

- 线速度和线加速度限制；
- 角速度和角加速度限制；
- `0.2 s`无命令超时及停车；
- 过大有限值、NaN、正Infinity和负Infinity输入；
- 异常输入后的合法命令恢复；
- 公共命令接口与控制器私有输入的隔离。

全部命令只发送到隔离的Gazebo Fortress仿真，未连接实体设备或AI Agent。超时和加速度
判定使用`/robot/odom`消息时间戳对应的ROS仿真时间，不使用受实时因子影响的墙钟时间。

## 2. 首轮发现与修复

首轮直接向`diff_drive_controller`发送NaN后，Gazebo拒绝了非有限轮速，但控制器内部限速
状态被NaN污染，后续合法命令无法恢复，并持续产生无效轮速错误。因此不能把Gazebo底层
拒绝视为公共接口的安全处理。

修复后命令链为：

```text
/robot/cmd_vel
→ cmd_vel_safety_filter
→ /robot/controller_cmd_vel
→ diff_drive_base_controller
```

过滤节点检查`Twist`的全部6个分量。所有分量均为有限数值时原样转发，由差速控制器执行
速度和加速度限制；任一分量为NaN或Infinity时拒绝原命令并向控制器发送零速度命令。

## 3. 定量结果

| 场景 | 输入 | 实测结果 | 结论 |
|---|---|---|---|
| 线速度过大 | `linear.x=2.0 m/s` | 峰值`0.600 m/s` | 通过 |
| 线加速度 | 从静止输入`2.0 m/s` | 最大采样斜率`1.000 m/s²` | 通过 |
| 命令超时 | 达到限速后停止发布 | `0.2 s`窗口内保持，随后减速至停车 | 通过 |
| 角速度过大 | `angular.z=5.0 rad/s` | 峰值`1.500 rad/s` | 通过 |
| 角加速度 | 从静止输入`5.0 rad/s` | 最大采样斜率`3.000 rad/s²` | 通过 |
| 非有限输入 | NaN、`+Infinity`、`-Infinity` | 转换为零速，里程计保持有限 | 通过 |
| 异常后恢复 | 随后输入`linear.x=0.2 m/s` | 正常运动且峰值不超过命令值 | 通过 |

控制器连接复核确认：`/robot/cmd_vel`只有安全过滤节点订阅；过滤节点发布
`/robot/controller_cmd_vel`，该私有Topic只有差速控制器订阅。非有限命令不再能够绕过
过滤节点直接进入控制器。

## 4. Gazebo GUI人工确认

用户于2026年8月4日在Gazebo GUI中完成可视化确认：

- 发送`linear.x=2.0 m/s`过大命令时，小车平滑前进，停止发布后自动停车；
- 发送`angular.z=5.0 rad/s`过大命令时，小车原地转向，停止发布后自动停车；
- 发送NaN命令后，小车未出现跳动或失控；
- 两次发送`linear.x=0.2 m/s`合法命令，用户确认小车均能恢复低速前进并最终自动停车。

人工观察与自动采样结论一致，W7人工可视化验证通过。

## 5. 自动检查入口

运行时检查器：

```bash
ROS_DOMAIN_ID=<隔离域> python3 scripts/check_m2_w7_safety.py
```

过滤函数单元测试覆盖正常有限值及6个`Twist`分量上的NaN、正Infinity、负Infinity。
运行时检查器覆盖限速、加速度、超时、非有限输入和恢复行为。完整Launch/场景自动编排、
最小rosbag及证据清单在M2-W8固化。

## 6. 已知边界

- 安全过滤节点只负责拒绝非有限输入；过大但有限的速度由成熟差速控制器按冻结参数限幅；
- `0.2 s`表示控制器开始执行超时停车的窗口，实际速度按已冻结加速度限制平滑降为零；
- 根Link惯量仍会产生KDL提示，但不影响本次Gazebo控制、里程计和安全验证；
- W7通过不代表M2验收完成，当前入口为M2-W8自动回归与证据。
