# M1已知遗留问题

以下事项不阻止M1验收，但必须在指定阶段继续处理。

| 遗留事项 | 风险 | 后续入口和关闭条件 |
|---|---|---|
| `ros-humble-nav2-msgs`尚未作为项目运行依赖全局安装 | 真实Nav2节点启动时可能缺少接口包 | M2～M5声明软件包和CI依赖，并通过真实Service/Action测试 |
| 运行时频率、QoS兼容、TF唯一发布者和时间跳变尚未随真实节点验证 | 静态契约通过不代表运行行为合格 | M2以后随对应节点加入自动测试并保存证据 |
| 人员感知、综合状态、非AI任务管理和详细安全状态Schema尚未冻结 | 后续接口可能补充或升级 | 在对应对象实现前设计，破坏性变更提升接口版本 |
| 大型验收证据外部存储服务未选定 | 后续大规模rosbag不适合进入Git | 首次产生需长期保存的大型证据前确定存储、校验和保留策略 |
| Gazebo Classic已结束支持 | 回退路线存在维护风险 | M2～M6保持Fortress主线，Classic只在明确回退条件下使用 |
| rosbag可能包含运动命令 | 错误回放可能影响实体底盘 | 实体接入前强制排除或重映射`cmd_vel`并执行安全审查 |

G1、G2及实体安全边界继续有效，不得用延期事项绕过阶段门。
