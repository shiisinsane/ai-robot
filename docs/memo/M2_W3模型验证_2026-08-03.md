# M2-W3 URDF/Xacro模型验证记录

## 1. 验证范围

验证`ai_robot_description`软件包的Xacro展开、URDF结构、W2参数映射、安装结果和
`robot_state_publisher`加载行为。本次不启动Gazebo、控制器或机器人运动。

## 2. 模型结构

- 根Link：`base_link`；
- Link数：6；
- Joint数：5；
- 连续关节：`left_wheel_joint`、`right_wheel_joint`；
- 固定关节：`base_footprint_joint`、前后支撑关节；
- 物理Link均具备visual、collision、正质量和惯量；
- `base_footprint`是无惯量辅助Frame；
- W3模型未包含Gazebo或`ros2_control`配置。

## 3. 自动验证

执行：

```bash
xacro src/robot_core/ai_robot_description/urdf/ai_robot.urdf.xacro \
  model_config:=$PWD/config/common/robot_model.yaml | check_urdf /dev/stdin
python3 scripts/check_robot_description.py
bash scripts/build.sh
bash scripts/test.sh
```

结果：

- Xacro展开和`check_urdf`解析通过；
- 3个ROS 2软件包构建通过；
- 包内汇总6项测试通过，0错误、0失败；
- 仓库级pytest 21项通过；
- 接口、W2参数和W3描述检查全部通过；
- Python flake8和语法检查通过。

## 4. robot_state_publisher验证

使用独立`ROS_DOMAIN_ID=83`启动安装后的`display.launch.py`，不启动Gazebo。结果：

- `/tf_static`收到`base_link → base_footprint`及固定支撑Frame；
- 向`/robot/joint_states`发布左右轮零位后，`/tf`收到
  `left_wheel_link`和`right_wheel_link`；
- TF Topic显式映射到全局`/tf`和`/tf_static`；
- 节点可正常停止，未发送速度或运动命令。

## 5. 结论

W3通过。模型已经成为ROS 2可解析、可安装和可发布TF的数字机器人骨架，并保持W2唯一
参数源和M1 TF契约。模型在物理引擎中的接触、稳定性、漂浮、翻倒和重复生成属于W4验证。
