# M3-W2传感器参数与TF基线验证记录

> 日期：2026年8月4日  
> 结论：通过，允许进入M3-W3激光雷达单元

## 1. 参数唯一来源

新增`../../config/common/sensor_model.yaml`作为M3传感器首版参数唯一来源，版本为`m3.v1`。
该文件只冻结接口、安装、频率、量程、成像、噪声和协方差，不在W2提前加载Gazebo插件。

## 2. 安装与TF基线

| 对象 | 父Frame | 子Frame | `xyz`（m） | `rpy`（rad） |
|---|---|---|---|---|
| 雷达 | `base_link` | `laser_link` | `[0.0, 0.0, 0.10]` | `[0.0, 0.0, 0.0]` |
| 相机机体 | `base_link` | `camera_link` | `[0.18, 0.0, 0.08]` | `[0.0, 0.0, 0.0]` |
| 彩色光学Frame | `camera_link` | `camera_color_optical_frame` | `[0.0, 0.0, 0.0]` | `[-π/2, 0.0, -π/2]` |
| IMU | `base_link` | `imu_link` | `[0.0, 0.0, 0.04]` | `[0.0, 0.0, 0.0]` |

- `base_link`继续采用REP-103：x前、y左、z上；
- 相机光学Frame采用z前、x右、y下；
- 安装点均位于M2底盘长宽投影范围内；
- Frame名称唯一且不包含`sim`、Gazebo版本或厂商名称；
- 静态TF责任属于`robot_state_publisher`，传感器桥接不得重复发布。

## 3. 数据参数基线

### 3.1 激光雷达

- `/robot/scan`，`sensor_msgs/msg/LaserScan`，`sensor_stream`；
- 360°、360点、15 Hz；该值在W3首次GUI实测后由10 Hz调整，以保证墙钟接收频率满足
  M1最低10 Hz契约；
- 量程`0.12～8.0 m`，分辨率`0.01 m`；
- 高斯噪声均值0、标准差`0.01 m`。

### 3.2 RGB相机

- `/robot/camera/color/image_raw`与`camera_info`，`sensor_stream`；
- `640×480`、`R8G8B8`/`rgb8`、15 Hz；
- 水平视场`π/3`，裁剪范围`0.05～20.0 m`；
- 高斯噪声均值0、标准差0.005；
- M3首版不启用深度接口，M1中的深度Topic继续保持条件状态。

### 3.3 IMU

- `/robot/imu/data`，`sensor_msgs/msg/Imu`，`imu_stream`，50 Hz；
- 提供方向、角速度、含重力的线加速度；
- 角速度噪声标准差`0.002 rad/s`，协方差对角值`4e-6`；
- 线加速度噪声标准差`0.02 m/s²`，协方差对角值`4e-4`；
- 方向协方差对角值`1e-4`；实际方向与重力语义在W5运行验证。

### 3.4 仿真编码器

- 继续复用`/robot/joint_states`和M2左右轮关节；
- 位置单位rad，速度单位rad/s，最低20 Hz；
- 前进时左右轮均为正；逆时针原地转向时左轮负、右轮正。

## 4. 自动验证

新增：

- `../../scripts/check_sensor_model.py`；
- `../../tests/unit/test_sensor_model_validator.py`；
- `scripts/test.sh`中的传感器参数检查入口。

验证结果：当前配置成功分支通过；相机频率过低、错误optical旋转和IMU协方差不匹配三个
失败分支均被正确拒绝，共4项单元测试通过。

## 5. 边界与下一步

W2通过仅表示参数和TF设计已冻结，不表示传感器Link、Gazebo插件或运行数据已经接入。
下一步M3-W3按该基线接入`laser_link`、GPU Lidar和单向`/robot/scan`桥接，并验证实际
角度、距离、频率、时间戳、QoS、Frame及GUI/RViz2显示。
